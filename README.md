## 프로젝트 개요

본 프로젝트는 간단한 쉘을 구현하는 것을 목표로 합니다. C 언어를 사용하여 개발되었으며, 기본적인 명령어 처리, 파이프, 리디렉션, 환경 변수 처리 등의 기능을 포함합니다.

## 구현 기능

* 프롬프트 표시 및 사용자 입력 대기
* 명령어 히스토리 기능
* PATH 환경 변수 및 상대/절대 경로를 이용한 실행 파일 검색 및 실행
* 하나의 전역 변수를 사용하여 수신된 신호 처리 (ctrl-C, ctrl-D, ctrl-\)
* 따옴표 처리 ('', "")
* 리디렉션 (<, >, <<, >>)
* 파이프 (|)
* 환경 변수 확장 ($VAR, $?)
* Built-in 명령어 처리 (echo, cd, pwd, export, unset, env, exit)

## 사용법

1.  저장소 클론
2.  `make` 명령어를 통해 컴파일
3.  `./minishell` 을 실행하여 쉘 실행

## 미구현 기능 (보너스 제외)

본 프로젝트에서는 아래 기능과 같은 보너스 요구사항을 구현하지 않았습니다.

* `&&` 및 `||` 연산자와 괄호를 이용한 우선순위 처리
* 와일드카드 처리

## 참고 사항

* `readline()` 함수는 메모리 누수를 발생시킬 수 있으나, 이는 과제에서 수정하지 않아도 되는 부분입니다.
* 쉘의 동작에 대한 추가적인 정보가 필요할 경우, bash 쉘을 참고하는 것이 좋습니다.
